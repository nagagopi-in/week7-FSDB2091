# Week 7 - Web Development Training Tasks

This repository contains the work completed for Week 7 of the FSDB2091 Web Technologies training.

## Overview

The tasks in this repository focus on backend web development concepts using Node.js. You will find implementations covering server setup, routing, controller logic, and model definitions—supporting a modular and maintainable codebase.

## Learning Outcomes

- Understand backend server architecture with Node.js.
- Practice modular coding and organization.
- Setup and use environment variables for configuration.
